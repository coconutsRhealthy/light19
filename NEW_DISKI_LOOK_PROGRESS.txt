MOCKUPS (mockups/ at repo root — untracked, NOT built)
------------------------------------------------------
Self-contained "bundler" HTML. The real React/Babel component is a
gzipped asset in a <script type="__bundler/manifest"> referenced by a
<script type="text/babel" src="UUID">. Each file has TWO babel scripts:
  1) shared chrome (tokens / Nav / Footer)   2) the page itself (LAST one)
To read a page's design, extract the LAST text/babel asset:
  - decode the JSON-escaped string on the __bundler/template line
  - regex the text/babel src UUIDs, take the last
  - base64-decode + gunzip that manifest entry -> JSX
(A python helper for this was used at /tmp/extract_page.py — recreate if gone.)

PER-PAGE APPROACH
-----------------
- Wire to real data/services where it maps; placeholder copy for
  sections with no backing data (mark them in the code).
- Keep all existing logic (data fetch, search, pagination, modals,
  gtag/analytics calls, routerLinks). Restyle markup only.
- Text/CSS over images for perf.
- Verify with headless Chrome at 390px AND desktop. Catch horizontal
  overflow by checking document.documentElement.scrollWidth === viewport.
  (Watch for messy feed data: e.g. Prikbord rows put long text in the
  percentage field + a URL in code — use stacked layout + break-words.)
- One `newlook:` commit per page.
