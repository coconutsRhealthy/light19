Diski / Samenwerken
Voor creators & partners

Deel jouw kortingscode op Diski

Heb jij een eigen kortingscode? Wij delen die graag met onze shoppers — en we staan open voor een langere samenwerking. Dat kan een win-winsituatie zijn: jij krijgt meer bereik en meer mensen die jouw code gebruiken, wij bieden onze bezoekers nóg betere deals.

Diski wordt elke dag bezocht door mensen die actief op zoek zijn naar kortingscodes — precies het publiek dat jij wilt bereiken. We werken graag op een manier die voor ons allebei goed voelt, en zijn flexibel in hoe we dat invullen. Hieronder een paar opties; heb je zelf een idee, dan horen we dat graag.

Manieren waarop we kunnen samenwerken

Van simpel en vrijblijvend tot een echte partnership.

🏷️

We zetten jouw code online

De simpelste vorm: stuur ons je code en wij plaatsen hem op Diski, zodat duizenden shoppers hem kunnen vinden en gebruiken.

🤝

Een langere samenwerking

Zit er meer in? We gaan graag een structurele samenwerking aan, bijvoorbeeld met een eerlijke verdeling van de opbrengsten die jouw code oplevert.

📲

Cross-promotie

Jij deelt Diski af en toe in je stories, wij geven jouw code en kanaal extra zichtbaarheid. Zo helpen we elkaar groeien.

💡

Jouw eigen idee

Heb je een ander voorstel in gedachten? Laat het ons weten — we denken graag mee en staan open voor creatieve afspraken.

Win-win? Laten we praten

Neem contact met ons op

Mail ons je code of je idee voor een samenwerking. We reageren snel en denken graag met je mee over wat voor ons allebei werkt.
