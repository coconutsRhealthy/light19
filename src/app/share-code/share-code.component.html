Deel jouw kortingscode op Diski

Heb jij een eigen kortingscode en wil je hem zichtbaar maken voor duizenden shoppers? Dat kan! Plaats jouw code gratis op Diski en bereik precies de mensen die op zoek zijn naar een goede deal.

Zo werkt het

In drie simpele stappen staat jouw code online.

  1. 1

    Kies een afbeelding

    Pak een van de onderstaande Diski-afbeeldingen — ze zijn gemaakt om mooi in je Instagram-story te passen.

  2. 2

    Deel hem in je story

    Post de afbeelding in je Instagram-story en voeg een link toe naar diski.nl, zodat je volgers meteen kunnen doorklikken.

  3. 3

    Mail ons jouw code

    Stuur een mailtje met je code (en een screenshot van je story) naar info@diski.nl. Wij zetten jouw code dan zo snel mogelijk online.
